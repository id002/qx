# Quantumult X 去广告规则知识库

本知识库用于存放 Quantumult X 去广告规则相关的权威资料与整理笔记。

## 目录结构

- `00-原始资料/`：从官方仓库和规则仓库抓取的原始文件
  - `官方配置/`：官方 sample.conf、resource-parser.js 等
  - `去广告规则/`：GOODBYEADS、墨鱼、Anonymous0632 等规则仓库
  - `教程文档/`：不完全指南、语法参考等
- `01-整理笔记/`：AI 消化后的摘要与要点
- `02-规则模板/`：可直接复制使用的规则模板

## 工作流

```
00-原始资料 → 01-整理笔记 → 02-规则模板
```

## 定时任务

每周一上午 9:00 自动从权威资源抓取最新规则，更新知识库。
